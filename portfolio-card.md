# Portfolio Card

## Title
Org Chart Automation Pipeline

## One-liner (for a card/tile view)
Replaced a manually-dragged-and-dropped org chart with an automated pipeline that gives leadership instant visibility into staffing, with no more counting boxes by hand.

## Short description (2 to 3 sentences, for a card body)
The team's org chart was a hand-edited diagram in in a .ppt file. Every staffing change meant manually dragging boxes and recoloring cells. I rebuilt it as a pipeline: a structured spreadsheet feeds a Python script that generates a live, interactive chart automatically. What used to take 20 to 30 minutes of manual layout work is now a single script run, and leadership can click any category, like Remote, Veteran, or Open Position, to instantly see who's in it across the whole organization.

## Key results (bullets, for expanded view)
- Eliminated manual chart editing. Staffing changes are now a spreadsheet edit, not a redraw
- Automatic headcount roll-ups at every level of the org, with zero manual counting
- One-click filtering answers staffing questions instantly instead of requiring a manual scan
- Scales from a 2-person team to a 20+ person team without the layout breaking down
